# SUNO AI – College Enquiry Assistant

SUNO AI is a smart College Enquiry Assistant designed to help students and parents get quick information about college admissions, courses, departments, fees, placements, hostel facilities and campus life.

The system supports both **English and Thanglish**, making college-related information easier and more accessible for students.

## 🚀 Features

- AI-style College Enquiry Assistant
- English + Thanglish support
- Admission information
- Course information
- Department details
- Fee enquiry
- Placement information
- Hostel information
- Quick question buttons
- Interactive chat interface
- Responsive design for desktop and mobile
- Course PDF viewing
- Modern dark UI with SUNO AI branding

## 💬 AI Assistant

Students can ask questions such as:

- "IT course iruka?"
- "Admission epdi apply panrathu?"
- "Fees evlo?"
- "What departments are available?"
- "Tell me about placements"
- "Hostel facility iruka?"

SUNO AI provides responses in a simple and student-friendly format.
